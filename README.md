# GitHub Desktop 練習用ファイル

GitHub Desktopの基本操作を試すためのサンプルです。

## 入っているファイル

- `001-index.html`：Webページ本体
- `002-style.css`：ページの見た目を整えるCSS
- `README.md`：この説明ファイル

## 確認方法

`001-index.html` をダブルクリックしてブラウザで開くと、
「Hello World!」と表示されます。

## 練習してみよう

たとえばHTMLの文章を少し変更して、

1. GitHub Desktopで変更を確認する
2. Commitする
3. Pushする

という流れを試してみてください。
